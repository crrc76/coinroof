升级服务器

升级只替换程序，不动数据文件夹，账目和照片都会保留。

怎么知道有新版本

  • App 里：“我的 → 同步与备份”会显示“家庭服务器有新版本”和更新说明，“我的”页面上也会出现红点。
  • 电脑版窗口里：“更新”一栏会显示新版本号。
  • 用到新功能时：如果 App 的某个功能需要更新的服务器，点它时会提示先升级服务器。

服务器每天会从本网站读取一次最新版本号，只是下载一个很小的文件，不会上传任何数据。

Windows / Mac 电脑版

在服务器窗口里点立即更新。程序会下载新版、校验完整性，然后自动重启，前后大约一分钟。

如果自动更新失败，可以手动更新：点“退出服务器”，再下载 Windows 版或 Mac 版，替换旧程序后打开。数据位置不变。

群晖

Container Manager → 项目 → 选中 coinroof → 操作 → 停止，再点构建。会下载最新镜像并重新启动。

也可以用 SSH 登录 NAS，在 docker/coinroof 文件夹里执行 sudo docker compose pull && sudo docker compose up -d。

威联通

见威联通安装教程里的“升级”一节。

Linux / 树莓派

cd ~/coinroof
docker compose pull && docker compose up -d

升级之后

不用在手机上做任何操作。App 下次同步时会自动识别新版本，原来提示升级的地方会消失。

Updating the server

Updating replaces the program only. The data folder isn’t touched, so all records and photos are kept.

How you’ll know there’s an update

  • In the app: “Me → Sync & backup” shows “Home server update available” with what’s new, and a red dot appears next to Sync & backup on the Me tab.
  • In the Windows / Mac server window: the “Updates” section shows the new version.
  • When you use a new feature: if a feature needs a newer server, the app tells you to update the server first.

Once a day the server reads the latest version number from this website. It only downloads a tiny file and never uploads any data.

Windows / Mac app

Click Update now in the server window. It downloads the new version, verifies it and restarts automatically, in about a minute.

If the automatic update fails, update by hand: click “Quit server”, download the Windows or Mac version again, replace the old program and open it. Your data location stays the same.

Synology

Container Manager → Project → select coinroof → Action → Stop, then Build. This downloads the latest image and starts it again.

Or SSH into the NAS and, in the docker/coinroof folder, run sudo docker compose pull && sudo docker compose up -d.

QNAP

See “Updating” in the QNAP guide.

Linux / Raspberry Pi

cd ~/coinroof
docker compose pull && docker compose up -d

After updating

Nothing to do on the phones. The app picks up the new version the next time it syncs, and the update notices go away.
