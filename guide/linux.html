在 Linux / 树莓派上安装

用 Docker 运行，几条命令就好。镜像同时支持 x86-64 和 ARM64（树莓派 4/5 请装 64 位系统）。

  1. 安装 Docker

    还没装的话，执行官方安装脚本：

    curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER   # 之后重新登录，免得每次都加 sudo
  2. 写配置文件 
    mkdir -p ~/coinroof && cd ~/coinroof
cat > docker-compose.yml <<'EOF'
services:
  coinroof:
    image: ghcr.io/crrc76/coinroof-server:latest
    container_name: coinroof
    restart: unless-stopped
    ports:
      - "8000:8000"
    volumes:
      - ./data:/data
    environment:
      - TZ=Asia/Shanghai
EOF
  3. 启动 
    docker compose up -d
curl http://localhost:8000/api/health   # 看到 "ok":true 就成功了

    开了防火墙（如 ufw）的话，放行 8000 端口：sudo ufw allow 8000/tcp。

  4. 连接手机

    按连接手机操作，地址是这台机器的局域网 IP（hostname -I 可以查看）。

升级

cd ~/coinroof
docker compose pull && docker compose up -d

想全自动升级，可以再加一个 Watchtower 容器。不过自动升级出问题时你不会马上知道，建议还是看到 App 里的提示后手动升级。

数据与备份

全部数据在 ~/coinroof/data。见备份与恢复。

Install on Linux / Raspberry Pi

Run it with Docker in a few commands. The image supports both x86-64 and ARM64 (on a Raspberry Pi 4/5, use a 64-bit OS).

  1. Install Docker

    If you don’t have it yet, use the official install script:

    curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER   # log in again afterwards so you don't need sudo
  2. Create the config file 
    mkdir -p ~/coinroof && cd ~/coinroof
cat > docker-compose.yml <<'EOF'
services:
  coinroof:
    image: ghcr.io/crrc76/coinroof-server:latest
    container_name: coinroof
    restart: unless-stopped
    ports:
      - "8000:8000"
    volumes:
      - ./data:/data
    environment:
      - TZ=Europe/London
EOF
  3. Start it 
    docker compose up -d
curl http://localhost:8000/api/health   # "ok":true means it's working

    If a firewall such as ufw is on, allow port 8000: sudo ufw allow 8000/tcp.

  4. Connect your phone

    Follow Connect phones & family. The address is this machine’s LAN IP (see hostname -I).

Updating

cd ~/coinroof
docker compose pull && docker compose up -d

For fully automatic updates you can add a Watchtower container. But if an automatic update goes wrong you won’t notice right away, so we suggest updating by hand when the app tells you a new version is out.

Data and backups

All data is in ~/coinroof/data. See Backup & restore.
