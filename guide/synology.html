在群晖 NAS 上安装

NAS 本来就一直开着，用来跑家庭服务器最省心。下面以 DSM 7.2 的 Container Manager 为例。

需要支持 Container Manager 的机型（大多数 x86 和较新的 ARM 机型都支持）。

  1. 安装 Container Manager

    打开套件中心，搜索 Container Manager，安装。

  2. 建一个文件夹放数据

    打开 File Station，在 docker 共享文件夹里新建文件夹 coinroof，再在里面新建 data 文件夹。全家的账目和照片都会保存在这里。

  3. 创建项目

    打开 Container Manager → 项目 → 新增：

    • 项目名称：coinroof
    • 路径：选择刚才建的 docker/coinroof
    • 来源：创建 docker-compose.yml，把下面的内容粘贴进去
    services:
  coinroof:
    image: ghcr.io/crrc76/coinroof-server:latest
    container_name: coinroof
    restart: unless-stopped
    ports:
      - "8000:8000"
    volumes:
      - ./data:/data
    environment:
      - TZ=Asia/Shanghai

    一路点“下一步”，最后勾选创建完成后启动项目，点“完成”。第一次会下载镜像，稍等一两分钟。

  4. 确认运行

    项目状态显示“运行中”就好了。在电脑浏览器里打开 http://NAS的IP:8000/api/health，看到 "ok":true 说明服务器正常。

    如果开了 DSM 的防火墙，记得在“控制面板 → 安全性 → 防火墙”里放行 8000 端口。

  5. 连接手机

    打开手机上的 Coinroof，按连接手机操作。地址就是 NAS 的 IP。

升级与备份

  • 升级：Container Manager → 项目 → 选中 coinroof → 操作 → 停止，再点构建，会下载最新镜像并重新启动。数据在 data 文件夹里，不受影响。详见升级服务器。
  • 备份：用 Hyper Backup 备份 docker/coinroof 文件夹即可。见备份与恢复。

Install on a Synology NAS

A NAS is already on around the clock, which makes it the easiest home for your server. These steps use Container Manager on DSM 7.2.

Your model needs to support Container Manager (most x86 and newer ARM models do).

  1. Install Container Manager

    Open Package Center, search for Container Manager and install it.

  2. Create a folder for the data

    In File Station, create a folder coinroof inside the docker shared folder, and a data folder inside that. All of your family’s records and photos will be stored here.

  3. Create a project

    Open Container Manager → Project → Create:

    • Project name: coinroof
    • Path: the docker/coinroof folder you just made
    • Source: Create docker-compose.yml, and paste this in:
    services:
  coinroof:
    image: ghcr.io/crrc76/coinroof-server:latest
    container_name: coinroof
    restart: unless-stopped
    ports:
      - "8000:8000"
    volumes:
      - ./data:/data
    environment:
      - TZ=Europe/London   # your time zone

    Click Next through the wizard, tick Start the project once it is created, and click Done. The first start downloads the image, which takes a minute or two.

  4. Check it’s running

    The project should show “Running”. On a computer, open http://NAS-IP:8000/api/health in a browser; "ok":true means the server is up.

    If DSM’s firewall is on, allow port 8000 under “Control Panel → Security → Firewall”.

  5. Connect your phone

    Open Coinroof on your phone and follow Connect phones & family. The address is your NAS’s IP.

Updating and backups

  • Update: Container Manager → Project → select coinroof → Action → Stop, then Build. This downloads the latest image and starts it again. Your data in the data folder is kept. See Updating the server.
  • Back up: include the docker/coinroof folder in Hyper Backup. See Backup & restore.
