连接手机、添加家人

服务器装好后，先由一个人连接并创建管理员账号，再由管理员添加家人。

连接前请确认：手机和服务器连着同一个 WiFi，服务器正在运行。

第一个人：创建家庭

  1. 打开连接页面

    打开 Coinroof，进入我的，点顶部卡片上的连接。

  2. 自动查找服务器

    点自动查找家里的服务器，一般几秒就能找到。找到多台时，选你刚装的那台。

    找不到的话，在“服务器地址”里手动输入服务器窗口上显示的地址（比如 192.168.1.10，端口是 8000 时可以不写），再点连接。还是不行，看常见问题。

  3. 创建管理员账号

    新服务器上还没有账号，App 会请你创建第一个账号，这个账号就是管理员。填用户名、密码和称呼（比如“爸爸”），完成。

    手机上之前单机记过的账、建过的分类和账户，会一起上传到服务器。

添加家人

  1. 管理员添加账号

    在管理员的手机上：我的 → 账号与家庭 → 家庭成员，点右下角的添加按钮，为家人设置用户名和初始密码。

  2. 家人连接并登录

    家人在自己的手机上：我的 → 连接 → 自动查找家里的服务器，然后用管理员给的用户名和密码登录。登录后可在“账号与家庭”里修改密码。

家庭共享需要高级版。家中任一成员购买后，全家都能同步。还没购买时，账号照样能创建，各自的手机照常记账，购买后自动同步上来。

之后

  • 同步是自动的：记账后几秒内同步，打开 App 时也会同步。在我的 → 同步与备份里可以看到同步状态，也能手动同步。
  • 默认只在 WiFi 下自动同步。想在外面也同步，看在外面也能同步。
  • 服务器的 IP 变了（比如路由器重启后）？在 App 里点我的 → 重新连接 → 自动查找即可，数据不会丢。

Connect phones & add your family

Once the server is running, one person connects first and creates the admin account. The admin then adds everyone else.

Before connecting, make sure your phone and the server are on the same Wi‑Fi and the server is running.

First person: create the family

  1. Open the connect screen

    Open Coinroof, go to Me, and tap Connect on the top card.

  2. Find the server

    Tap Find my home server. It usually takes a few seconds. If several are found, pick the one you just set up.

    If nothing is found, type the address shown in the server window into “Server address” (such as 192.168.1.10; you can leave out the port if it’s 8000) and tap Connect. Still stuck? See Troubleshooting.

  3. Create the admin account

    A new server has no accounts yet, so the app asks you to create the first one. This account is the admin. Enter a username, password and display name (such as “Dad”).

    Anything you already recorded on this phone, plus your categories and accounts, is uploaded to the server.

Add your family

  1. The admin creates accounts

    On the admin’s phone: Me → Account & family → Family members, tap the add button, and set a username and starting password for each family member.

  2. Family members connect and sign in

    On each family member’s phone: Me → Connect → Find my home server, then sign in with the username and password from the admin. They can change their password later under “Account & family”.

Family sharing needs Premium. When one family member buys it, everyone can sync. Until then, accounts can still be created and everyone keeps recording on their own phone; it all syncs once Premium is bought.

After that

  • Syncing is automatic: within seconds of recording, and whenever the app opens. See the status, or sync by hand, in Me → Sync & backup.
  • By default the app syncs automatically on Wi‑Fi only. To sync while you’re out, see Sync away from home.
  • Server’s IP address changed (for example after a router restart)? In the app tap Me → Reconnect → Find my home server. No data is lost.
