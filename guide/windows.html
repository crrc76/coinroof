在 Windows 电脑上安装

下载一个程序，双击运行，就是家庭服务器。不用装别的软件，也不用敲命令。

适用于 Windows 10 / 11（64 位）。这台电脑最好一直开着，比如家里的台式机。

  1. 下载

    下载 Windows 版

    把下载的 CoinroofServer-windows.exe 放到一个固定的地方，比如“文档”文件夹，不要留在“下载”里以免被误删。

  2. 双击运行

    第一次打开时，Windows 可能提示“Windows 已保护你的电脑”。这是因为程序还没有购买代码签名证书，并不是病毒。点“更多信息”，再点“仍要运行”。

  3. 允许防火墙访问

    接着会弹出“Windows 安全中心警报”。勾选“专用网络”，点“允许”。这样家里的手机才能连上它。

    没看到这个弹窗、或者点了“取消”？看常见问题。

  4. 看到“运行中”就成功了

    窗口里会显示运行中和一个地址（比如 192.168.1.10），手机连接时会用到。

    建议勾选：

    • 开机自动启动：电脑重启后自动运行，不用每次手动打开。
    • 运行时不让电脑自动休眠：电脑休眠时家人无法同步。只阻止休眠，屏幕照常会关。
  5. 连接手机

    打开手机上的 Coinroof，按连接手机操作。

日常使用

  • 关掉窗口不会停止服务器，它只是最小化到任务栏。要真正关闭，点窗口里的“退出服务器”。
  • 数据在哪：默认在“文档\CoinroofServer”。窗口里点“打开文件夹”就能看到。备份方法见备份与恢复。
  • 笔记本电脑：合上盖子通常会休眠。可以在“控制面板 → 电源选项 → 选择关闭笔记本计算机盖的功能”里改成“不采取任何操作”。
  • 有新版本时窗口里会提示，点“立即更新”即可，数据不受影响。

Install on a Windows PC

Download one program and double-click it. That’s your home server. Nothing else to install, no commands to type.

For Windows 10 / 11 (64-bit). Ideally this computer stays on, like a desktop PC at home.

  1. Download

    Download for Windows

    Move CoinroofServer-windows.exe somewhere permanent, such as your Documents folder, rather than leaving it in Downloads where it may get cleaned up.

  2. Double-click to run

    The first time, Windows may say “Windows protected your PC”. That’s because the program isn’t code-signed yet; it isn’t a virus. Click More info, then Run anyway.

  3. Allow it through the firewall

    Next, a “Windows Security Alert” appears. Tick Private networks and click Allow, so phones at home can reach it.

    No alert, or clicked Cancel by mistake? See Troubleshooting.

  4. “Running” means it worked

    The window shows Running and an address (such as 192.168.1.10) that phones use to connect.

    We recommend turning on:

    • Start when I log in, so it runs again after a restart.
    • Keep the computer awake. Your family can’t sync while the PC sleeps. This only prevents sleep; the screen still turns off.
  5. Connect your phone

    Open Coinroof on your phone and follow Connect phones & family.

Day to day

  • Closing the window doesn’t stop the server; it just minimizes to the taskbar. To stop it, click Quit server.
  • Where your data lives: by default in “Documents\CoinroofServer”. Click “Open folder” in the window to see it. To back it up, see Backup & restore.
  • Laptops usually sleep when the lid closes. Change this in “Control Panel → Power Options → Choose what closing the lid does” to “Do nothing”.
  • When a new version is out, the window tells you. Click Update now; your data is kept.
