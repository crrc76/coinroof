备份与恢复

全家的账目和照片都在服务器的一个数据文件夹里。复制这个文件夹，就是一份完整备份。

数据在哪

安装方式数据文件夹
Windows / Mac 电脑版窗口里“数据”一栏显示的位置，默认是“文档/CoinroofServer”。点“打开文件夹”可直接打开
群晖docker/coinroof/data
威联通Container/coinroof/data
Linux / 树莓派~/coinroof/data

备份

  1. 先停止服务器

    电脑版点“退出服务器”；Docker 版停止容器。正在运行时复制，可能漏掉最近几分钟的改动。

  2. 复制整个数据文件夹

    复制到 U 盘、移动硬盘或网盘都可以。文件夹里的所有文件都要一起复制（包括 .db-wal 等文件）。

  3. 重新启动服务器

NAS 用户可以直接用群晖 Hyper Backup、威联通 HBS 3 定时备份这个文件夹。

每台手机也是一份备份。家人的手机上都保存着全家的账目；在“我的 → 同步与备份”里打开“在 WiFi 下保存全部照片”，照片也会存一份。服务器的硬盘坏了，也能用手机把数据找回来（见下文）。

恢复

从备份文件夹恢复

  • 电脑版：把备份文件夹复制回来，在窗口里点“更换位置…”选中它，服务器会重新启动并使用这份数据。
  • Docker 版：停止容器，把备份的内容放回 data 文件夹，再启动。

没有备份？用管理员的手机恢复

  1. 重新装好一个空的服务器（按对应的安装教程）。
  2. 用管理员的手机连接

    我的 → 重新连接 → 自动查找。App 发现服务器是空的，会提示用本机数据恢复服务器。输入管理员密码即可。

  3. 家人重新登录

    家人用原来的密码登录，他们手机上较新的记录会自动合并上来。

换一台电脑当服务器

  1. 在旧电脑上退出服务器，把数据文件夹复制到新电脑；
  2. 在新电脑上安装并打开服务器，点“更换位置…”选中这个文件夹；
  3. 手机上：我的 → 重新连接 → 自动查找，用原来的账号登录。

Backup & restore

All of your family’s records and photos live in one data folder on the server. Copy that folder and you have a complete backup.

Where the data is

Installed onData folder
Windows / Mac appShown under “Data” in the window, by default “Documents/CoinroofServer”. Click “Open folder” to open it
Synologydocker/coinroof/data
QNAPContainer/coinroof/data
Linux / Raspberry Pi~/coinroof/data

Back up

  1. Stop the server first

    In the app, click “Quit server”; with Docker, stop the container. Copying while it runs may miss the last few minutes of changes.

  2. Copy the whole data folder

    To a USB drive, external disk or cloud storage. Copy every file in the folder, including files such as .db-wal.

  3. Start the server again

On a NAS, you can schedule backups of this folder with Synology Hyper Backup or QNAP HBS 3.

Every phone is a backup too. Each family member’s phone keeps all of the family’s records. Turn on “Save all photos on Wi‑Fi” in “Me → Sync & backup” to keep the photos as well. If the server’s disk dies, you can get your data back from a phone (see below).

Restore

From a backup folder

  • Windows / Mac app: copy the backup folder back, click “Change…” in the window and choose it. The server restarts using that data.
  • Docker: stop the container, put the backup back into the data folder, and start it again.

No backup? Restore from the admin’s phone

  1. Set up a new, empty server using the install guide for your device.
  2. Connect with the admin’s phone

    Me → Reconnect → Find my home server. The app sees the server is empty and offers Restore server from this device. Enter the admin password.

  3. Family members sign in again

    They use their old passwords, and any newer records on their phones merge in automatically.

Moving the server to another computer

  1. On the old computer, quit the server and copy the data folder to the new computer.
  2. On the new computer, install and open the server, click “Change…” and choose that folder.
  3. On each phone: Me → Reconnect → Find my home server, and sign in with the same account.
