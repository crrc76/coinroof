在外面也能同步

默认只有在家里的 WiFi 下才能同步。不在家时照样能记账，回家后自动同步。如果想在外面也随时同步，推荐用 Tailscale。

不要在路由器上把 8000 端口直接映射到公网。家庭服务器用的是不加密的 HTTP，直接暴露在公网上，账本数据可能被别人看到。

用 Tailscale（推荐，免费）

Tailscale 会在你的手机和家里的服务器之间建一条加密的专用通道，不用改路由器设置。个人使用免费。

  1. 服务器那台设备装 Tailscale

    在 tailscale.com/download 下载对应版本（群晖、威联通可在套件中心 / App Center 里搜索 Tailscale），用一个账号登录。

  2. 每台手机装 Tailscale

    从应用商店安装 Tailscale，用同一个账号登录（家人手机可以用你的账号，或在 Tailscale 后台邀请）。

  3. 记下服务器的 Tailscale 地址

    在 Tailscale 里能看到服务器设备的地址，形如 100.x.x.x。

  4. App 里换成这个地址

    打开 Coinroof → 我的 → 重新连接，服务器地址填 100.x.x.x，连接后用原来的账号登录，数据不会丢。

  5. 允许用移动网络同步

    我的 → 同步与备份，关闭仅在 WiFi 下自动同步。

在家时，这个地址同样可用，不需要来回切换。

Sync when you’re away from home

By default the app syncs only on your home Wi‑Fi. You can still record while you’re out, and everything syncs when you get home. If you want to sync from anywhere, we recommend Tailscale.

Don’t forward port 8000 on your router to the internet. The home server uses unencrypted HTTP, so exposing it directly could let others see your ledger.

Use Tailscale (recommended, free)

Tailscale creates a private, encrypted connection between your phones and your home server, with no router changes. It’s free for personal use.

  1. Install Tailscale on the server device

    Download it from tailscale.com/download (on Synology or QNAP, search for Tailscale in Package Center / App Center) and sign in.

  2. Install Tailscale on each phone

    Install Tailscale from your app store and sign in with the same account (family members can use your account, or you can invite them from the Tailscale admin console).

  3. Note the server’s Tailscale address

    Tailscale shows the server device’s address, which looks like 100.x.x.x.

  4. Use that address in the app

    In Coinroof, go to Me → Reconnect, enter 100.x.x.x as the server address, and sign in with your existing account. No data is lost.

  5. Allow syncing on mobile data

    In Me → Sync & backup, turn off Auto-sync on Wi‑Fi only.

The same address works at home too, so you don’t need to switch back and forth.
