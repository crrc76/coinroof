常见问题

App 找不到服务器 / 连接超时

  1. 确认服务器在运行：电脑版窗口显示“运行中”；NAS 上容器在运行。
  2. 确认在同一个 WiFi：手机和服务器要连同一个路由器。不要连“访客 WiFi”，访客网络通常不让设备互相访问。
  3. 手机开了 VPN 或代理？VPN、加速器、代理类 App 可能会把局域网的连接也接管走，导致连不上家里的服务器。请暂时关闭，或在它的设置里让局域网地址直连（常叫“绕过局域网”）。
  4. 电脑防火墙拦住了：见下一条。
  5. 手动输入地址：在连接页面输入服务器窗口上显示的地址，比如 192.168.1.10。
  6. 用浏览器测试：在手机浏览器里打开 http://服务器地址:8000/api/health。能看到 "ok":true 说明网络是通的，问题在 App 这边；打不开说明网络或防火墙有问题。

Windows 防火墙拦住了

  1. 打开设置 → 隐私和安全性 → Windows 安全中心 → 防火墙和网络保护；
  2. 点允许应用通过防火墙 → 更改设置；
  3. 找到 CoinroofServer，勾选专用，确定。列表里没有的话，点“允许其他应用”添加它。

同时确认 Windows 把家里的网络识别为“专用网络”：设置 → 网络和 Internet → WLAN（或以太网）→ 点当前网络 → 网络配置文件类型选专用网络。

服务器关机或休眠了怎么办

没关系。大家照常在手机上记账，数据先存在手机里，服务器开机后自动同步，不会丢。电脑版可以勾选“运行时不让电脑自动休眠”。

电脑的 IP 地址变了

路由器重启后，电脑的 IP 可能会变，手机就连不上了。在 App 里点我的 → 重新连接 → 自动查找即可。想一劳永逸，可以在路由器设置里给这台电脑“固定 IP”（常叫 DHCP 静态分配、IP 与 MAC 绑定）。

提示端口 8000 被占用

说明电脑上已有其他程序用了 8000 端口。可以关掉那个程序；或者编辑服务器窗口提示里给出的 settings.json，把 "port": 8000 改成别的数字（如 8100），重新打开服务器。之后手机连接时地址要带上端口，如 192.168.1.10:8100。

杀毒软件报毒 / 打不开

电脑版是用 PyInstaller 打包的 Python 程序，个别杀毒软件可能误报。程序只在你的电脑上运行家庭服务器，除了每天从本网站读取一次版本号、更新时从 GitHub 下载新版，不会联系任何地方。可以把它加入杀毒软件的信任列表。

一台服务器能给几个家庭用？

一个。一台服务器就是一个家庭的账本。如果要给父母家单独用，请在他们家另装一台。

数据安全吗？

  • 数据只保存在你家的服务器和家人的手机上，开发者看不到。详见隐私政策。
  • 手机和服务器在家里用 HTTP 通信，没有加密，所以不要把服务器直接暴露到公网。需要在外面用时，请用 Tailscale。
  • 密码在服务器上只保存不可逆的哈希值。

Troubleshooting

The app can’t find the server / connection times out

  1. Check the server is running: the Windows / Mac window says “Running”; on a NAS, the container is running.
  2. Check you’re on the same Wi‑Fi: the phone and the server must use the same router. Avoid guest Wi‑Fi, which usually blocks devices from reaching each other.
  3. VPN or proxy on the phone? VPN, “accelerator” or proxy apps can take over local network traffic too, so the phone can’t reach your home server. Turn it off for now, or set it to bypass local addresses (often called “bypass LAN”).
  4. Computer firewall: see the next question.
  5. Enter the address by hand: type the address shown in the server window, such as 192.168.1.10, on the connect screen.
  6. Test in a browser: on the phone, open http://server-address:8000/api/health. If you see "ok":true, the network is fine and the problem is in the app. If it doesn’t load, it’s the network or a firewall.

Windows Firewall is blocking it

  1. Open Settings → Privacy & security → Windows Security → Firewall & network protection.
  2. Click Allow an app through firewall → Change settings.
  3. Find CoinroofServer and tick Private, then OK. If it’s not listed, add it with “Allow another app”.

Also make sure Windows treats your home network as private: Settings → Network & internet → Wi‑Fi (or Ethernet) → your network → set Network profile type to Private network.

What if the server is off or asleep?

No problem. Everyone keeps recording on their phones; the data is stored on the phone and syncs automatically once the server is back. Nothing is lost. In the Windows / Mac app you can turn on “Keep the computer awake”.

The computer’s IP address changed

After a router restart, the computer may get a new IP and phones can’t reach it. In the app, tap Me → Reconnect → Find my home server. To stop this happening, give the computer a fixed IP in your router settings (often called a DHCP reservation or static lease).

“Port 8000 is used by another program”

Another program on the computer is already using port 8000. Close that program, or edit the settings.json shown in the server window: change "port": 8000 to another number (such as 8100) and reopen the server. Phones then need the port in the address, such as 192.168.1.10:8100.

Antivirus flags it or won’t let it open

The Windows / Mac app is a Python program packaged with PyInstaller, which a few antivirus products mistakenly flag. It only runs your home server. Apart from reading the latest version number from this website once a day and downloading updates from GitHub, it contacts nothing. You can add it to your antivirus allow list.

Can one server serve several families?

No, one server is one family’s ledger. For your parents’ household, set up a separate server at their home.

Is my data safe?

  • Data is stored only on your home server and your family’s phones; the developer can’t see it. See the privacy policy.
  • At home, phones talk to the server over unencrypted HTTP, so don’t expose the server directly to the internet. To use it while you’re out, use Tailscale.
  • The server stores passwords only as one-way hashes.
